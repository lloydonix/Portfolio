F5 Studio

github.com/lloydonix/f5-studio

An offline Mac app that turns long scripts, such as study reviewers, lecture notes and tutoring scripts, into long-form audio with F5-TTS voice cloning. You pick a 5–10 second reference voice and it generates audio one paragraph at a time on the Apple GPU.

  • The generation queue survives restarts. Clips are keyed by their text, so editing one line regenerates only that line.
  • A shared pronunciation list handles Latin terms, names and acronyms, and numbers are written out as words before speaking.
  • Reference voices are trimmed, resampled to 24 kHz and transcribed with Whisper. Lines with an unusual pace are flagged for a listen.
  • A fact check flags numbers or citations that are missing compared with the source notes. The finished audio is exported as one merged MP3.
  • It's a native Swift wrapper around a local Python server. There are no accounts, no paid APIs, and nothing leaves the Mac.

The Cogitator

private repository

A study machine for my law notes. Open WebUI sits on a custom OpenAI-compatible bridge, and every question is answered from my Obsidian notes first, with the sources shown as links back into the vault.

  • Study modes: /digest writes case digests in my own Case Brief template from my notes plus LawPhil, the SC E-Library and the Official Gazette. It refuses rather than digest from memory. /recit runs recitation drills, and there are modes for elements and for distinguishing doctrines.
  • A PH Law Search toggle limits web lookups to trusted Philippine legal sources.
  • Quiz me and Save as Brief buttons sit under each answer. Saving drafts a new note into the right subject folder and links it from that subject's map of content. It never overwrites an existing note, and it backs up the map first.
  • Scriptorium writes tutor scripts from a reviewer and the notes it links to, in a chosen voice, and checks the numbers against the sources. The scripts go straight to F5 Studio to be read aloud.
  • Groq writes the answers by default and Mistral is the backup. Offline, a local qwen3 model writes them, and the note search always stays on the Mac.

Scientia Juria Mentor

private repository

A strictly grounded law-study tutor for my Obsidian vault. It answers only from my notes (and from trusted legal sites when I allow it), cites every claim, and refuses rather than guesses. It has a persona: Sakura Mina, a fictional law-school rival I created.

  • The pipeline is retrieval, then a draft, then a check of every claim against its citation. Unsupported claims are dropped, and a debug view shows why each one was kept or dropped.
  • The vault is opened read-only, and notes-only mode works fully offline.
  • An evaluation harness compares chat models side by side on the same questions.
  • Its retrieval and claim checks also power the Cogitator.

Vi

private repository

A private, local AI companion with long-term memory. The chat, the model and every memory stay on the Mac. It's the largest of these projects, with nearly a hundred commits in two weeks.

  • It runs as launchd services that start at login and restart if they crash, plus scheduled check-ins.
  • Prompts are ordered so Ollama can reuse cached work between messages, which brings replies down to about 5–10 seconds on 16 GB of memory.
  • An optional discoveries feed downloads a fixed list of public feeds through a safety pipeline and sends out nothing about the user.

The Council

private repository

Several mentor characters in one chat, inspired by Arthur Morgan, Joshua Graham, Musashi from Vagabond, and Arthas as the devil's advocate. The members with something to say reply, all written in one model pass and shown as separate colored bubbles.

  • Adding a member takes one persona file and one config entry.
  • It shares a single loaded model with Vi. Coordination code makes sure one app never unloads the model or pushes it out of memory while the other is using it.
